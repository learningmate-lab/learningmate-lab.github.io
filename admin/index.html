사이트 추가하는 법

① 새 사이트의 <head> 에 한 줄을 넣어요: <script src="https://learningmate-lab.github.io/track.js" data-site="새-사이트-id" defer></script>

② 포털 저장소의 sites.json 에 같은 id 로 한 줄을 추가하면 이 화면과 포털에 자동으로 나타나요. 활동 횟수를 세고 싶으면 사이트 코드에서 window.LMTrack && LMTrack.event('이름') 을 부르고, events 에 이름과 설명을 적어요.

숫자는 무료 카운터 서비스(Abacus)에 날짜별로만 저장돼요. 개인 정보는 보내지 않아요. 같은 학생이 다른 브라우저·기기로 들어오면 따로 세져요. 이 페이지는 검색에 안 나오게 해 두었지만 주소를 아는 사람은 볼 수 있어요.
