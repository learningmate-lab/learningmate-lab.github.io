사이트 추가 · 집계 방식

① 새 사이트의 <head> 에 한 줄: <script src="https://learningmate-lab.github.io/track.js" data-site="새-사이트-id" defer></script>

② 포털 저장소 sites.json 에 같은 id 로 한 줄 추가 → 이 화면과 포털에 자동으로 나타나요. 활동을 세려면 사이트 코드에서 window.LMTrack && LMTrack.event('이름'), events 에 이름과 설명.

숫자는 무료 카운터(Abacus)에 날짜별로만 저장돼요. 개인 정보는 보내지 않아요. 하루에 같은 브라우저 = 방문자 1명. 이 브라우저(관리자)는 집계에서 빠져요. 카운터 서비스가 10초에 30번까지만 응답해서, 처음 볼 때는 지난 기록을 천천히 채워요. 한 번 받은 날짜는 저장해 두고 다시 받지 않아요.
